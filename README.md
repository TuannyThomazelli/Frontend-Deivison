# 🚀 Projetos e Atividades Práticas - Frameworks Front-end

Este repositório contém os projetos, atividades práticas e estudos desenvolvidos durante as aulas da disciplina **Frameworks Front-end** no **SENAI**, sob orientação do **Prof. Me. Deivison S. Takatu** (`deivison.takatu@edu.senai.br`)[cite: 5, 7].

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Front-end:** React.js, Vue.js, Angular, Next.js, HTML5, CSS3, JavaScript / TypeScript[cite: 5]
* **Back-end:** Node.js, Express.js, CORS[cite: 7]
* **Consumo de APIs:** Fetch API, Axios, JSON[cite: 7]
* **Deploy e Nuvem:** Render (APIs), Vercel (Front-end)[cite: 7]
* **Versionamento & Ferramentas:** Git, GitHub, VS Code[cite: 5, 7]

---

## 📚 Conteúdo e Atividades Desenvolvidas

### 📌 Aula 03: Arquitetura e Frameworks Front-end
**Objetivo:** Compreender a diferença entre bibliotecas e frameworks[cite: 5], explorando a componentização e os ecossistemas do React, Vue, Angular e Next.js[cite: 5].

* **Atividade 01 - Desenvolvimento Multi-Framework:**[cite: 5]
  * Construção de quatro projetos web abordando o mesmo tema utilizando **React**, **Vue**, **Angular** e **Next.js**[cite: 5].
  * Apresentação de interfaces responsivas, componentizadas e versionadas no GitHub[cite: 5].
* **Atividade 02 - Análise Comparativa & Clone de Repositório:**[cite: 5]
  * Importação e execução do projeto de repositório open-source[cite: 5].
  * Elaboração de um relatório comparativo sobre reatividade, estrutura de pastas e curva de aprendizado[cite: 5].

---

### 📌 Aula 04: Consumindo APIs no Front-end
**Objetivo:** Entender a arquitetura REST[cite: 7], protocolo HTTP[cite: 7], manipulação do formato JSON[cite: 7] e criação/consumo de Web Services com Express e CORS[cite: 7].

* **Atividade 01 - Mapeamento de Projetos com APIs:**[cite: 7]
  * Análise de 10 projetos no GitHub que consomem APIs externas, documentando os frameworks e endpoints utilizados[cite: 7].

* **Atividade 02 - Criando e Consumindo uma API REST com Deploy em Nuvem:**[cite: 7]
  1. **API Back-end:** Desenvolvida em **Node.js** com **Express** e **CORS** para fornecimento de rota de data/hora atualizada[cite: 7].
     * 🌐 *Hospedada no Render:* `https://seu-projeto.onrender.com`[cite: 7]
  2. **Aplicação Front-end:** Interface web responsável por consumir a API no Render e apresentar as informações ao usuário[cite: 7].
     * 🌐 *Hospedada na Vercel:* `https://seu-projeto.vercel.app`[cite: 7]

### Pré-requisitos
* **Node.js** (v18 ou superior)
* **Git**

cd sua-api
