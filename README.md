# 🚀 Exercícios e Projetos - Frameworks Front-end

Projetos e atividades práticas desenvolvidos na disciplina de **Frameworks Front-end** no **SENAI**, sob orientação do **Prof. Me. Deivison S. Takatu** (`deivison.takatu@edu.senai.br`).

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript, Bootstrap, React, Vue, Angular, Next.js
* **Back-end & APIs:** Node.js, Express, CORS, JSON, Fetch API
* **Hospedagem & Ferramentas:** Render, Vercel, Git, GitHub

---

## 📚 Lista de Atividades

### 📌 Aula 01 & 02: Fundamentos Web & Frameworks CSS
* **Atividade 01 & 02:** Construção de páginas responsivas e estruturadas utilizando HTML, CSS, JavaScript Vanilla e frameworks CSS (como Bootstrap) para estilização de interfaces.

---

### 📌 Aula 03: Arquitetura e Frameworks Front-end
* **Atividade 01 (Projeto Multi-Framework):** Desenvolvimento de 4 aplicações sobre o mesmo tema utilizando **React**, **Vue**, **Angular** e **Next.js**.
* **Atividade 02 (Importação & Análise):** Clone de um projeto open-source no GitHub e produção de relatório comparativo entre as tecnologias utilizadas.

---

### 📌 Aula 04: Consumo e Criação de APIs REST
* **Atividade 01 (Mapeamento de APIs):** Mapeamento e documentação em Markdown de 10 projetos no GitHub que consomem APIs públicas.
* **Atividade 02 (API Express + Deploy):**
  * Criação de uma API REST com **Express** e **CORS** para retorno de data/hora, hospedada no **Render**.
  * Criação de uma aplicação Front-end para consumir a API, hospedada na **Vercel**.
